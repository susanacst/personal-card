# 🎀 Personal Card · Template Web

Este es un **template de tarjeta de presentación online** con un estilo **kawaii, rosita y amigable**, ideal para creadores de contenido, artistas, streamers, o cualquier persona que quiera tener una página cute para compartir sus links, redes y un poco de su mundo.

> ⚠️ Este proyecto **aún está en construcción**. Tiene varios detalles por pulir, ya que está siendo desarrollado como una **práctica personal** para explorar y mejorar el diseño web con un enfoque estético específico (del que aún me queda mucho por mejorar).  
> Me enfoqué primero en lograr una estructura y funcionamiento de lo más importante, para después irme hacia los detalles.

---

## 🌸 Características

- Página principal con bienvenida e imagen destacada
- Secciones adicionales:
  - 💌 Contacto
  - 📖 Lore / Sobre mí
  - 🤝 Apoyo (para links tipo Ko-fi, PayPal, etc.)
- Carrusel de tarjetas animadas
- Diseño responsive (se adapta a distintos tamaños de pantalla)
- Estilo visual kawaii, dulce y personalizado
- Botones de links de redes sociales

---

## 🛠 Tecnologías utilizadas

- HTML5 + CSS3
- JavaScript Vanilla
